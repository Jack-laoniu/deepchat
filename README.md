# 需求闯关

一句模糊需求 → 一局多邻国式小游戏 → 一份理清楚的方案。

不让用户填表，而是让他在游戏里自然地说出真实情况和真实意图：

- **小故事**（像听力故事）：几个角色吵吵闹闹地演出这个需求在现实里会踩的坑，台词逐句朗读，中途停下来问「你家是哪种？」
- **聊天 / 角色扮演**：向导狐狸、老板、家人跟你聊；可以点现成的回答，也可以打字或语音用自己的话说，关键词会影响后面的剧情，原话进交付物
- **地图任务**：在小镇里走动，找几个人打听，每个人问清一个方面
- **点选、滑卡、预算滑杆、拖工具修坑、Boss**：每个选择都会改变方案和价格，选错会「炸」出坑，赌一把可能翻车

通关后得到方案清单，以及一份给 AI 的上下文，分开写「用户原话 / 已确认 / 待核实 / 接受的风险 / 试过不行的做法」，可直接交给任意 AI 出详细方案。

```bash
npm install
npm run dev           # 本地玩
npm test              # 规则测试
npm run build:widget  # 单文件 HTML，用于嵌入 ChatGPT Apps / Claude
```

- `src/lesson/` 关卡格式、规则、交付物、给大模型的生成提示词（与界面无关）
- `src/rounds/` 玩法：Talk（故事/聊天）、Map（地图）、Pick、Swipe、Slider、Repair（修坑/Boss）
- `src/lessons/` 示例关卡
- 插画：Google Noto 表情（静态 SVG + Lottie 动画），关卡里只需写 emoji 字符；朗读和语音输入用浏览器自带能力
