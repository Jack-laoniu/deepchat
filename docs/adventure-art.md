# 冒险地图（Adventures 式）美术需求

> 现状：场景、道具、人物已经全部用代码矢量画好、能玩（`src/rounds/adventure/props.tsx`、`src/chars/Character.tsx`）。
> 这份清单是**升级用**的：按下面的规格出图，替换进去就能直接变精致，不用改玩法代码。
> 参考：多邻国 Adventures（公园、餐车、长椅那种画面）。

## 1. 统一画风（所有图都要遵守）

| 项 | 要求 |
|---|---|
| 视角 | 斜上方俯视，约 26°：**同时看得到东西的顶面和正面**（顶面亮、正面暗） |
| 光 | 左上方来光；影子落在右下 |
| 线条 | 深棕描边 `#3A2A26`，粗细统一（1024px 图上约 6px） |
| 上色 | 平涂 + 一层高光，不要渐变质感、不要写实 |
| 人物 | 沿用现在游戏里的 Q 版矢量小人（大头、圆脸、短身子），**不要**换成设定图那种头身比 |
| 格式 | 透明底 PNG 或 SVG；道具按「格」出图，1 格 = 256px 宽 |
| 命名 | `prop_<名字>.png`、`decor_<名字>.png`、`floor_<场景>.png`、`me_<方向>_<帧>.png` |

## 2. 地面和围边（每个场景一套）

场地是 7 列 × 9 行的格子。每个场景要：

| 文件 | 内容 | 尺寸 |
|---|---|---|
| `floor_<scene>.png` | 可平铺的 2×2 格地砖 | 512×512 |
| `edge_<scene>.png` | 场地外一圈（草坪 / 墙脚），可平铺 | 512×128 |
| `back_<scene>.png` | 后排：室外是围栏 + 树篱，室内是带窗户的墙 | 1900×450 |

场景五个：`street`（小区楼下 / 街道）、`park`（公园）、`home`（客厅，木地板）、`shop`（店里）、`office`（办公室）。

## 3. 地点大道具（NPC 守在旁边）

「宽」指占几格，「高」指画出来几格高（含顶面）。底边要和格子底边对齐。

| 名字 | 宽×高 | 说明 |
|---|---|---|
| `building` | 2×2.3 | 小楼正面：屋顶、窗户、门、雨棚，门上方留一块空白招牌位 |
| `counter` | 2×1.3 | 前台 / 柜台，NPC 站在后面，只露上半身；收银机放在最边上 |
| `kiosk` | 2×2.1 | 小摊 / 餐车：雨棚 + 柜台，**中间镂空**（摊主站在里面） |
| `car` | 2×1.25 | 车，正前方 3/4 视角 |
| `sofa` | 2×1.2 | 沙发 |
| `bench` | 2×1.1 | 公园长椅 |
| `desk` | 1×1.45 | 书桌 + 显示器（显示器放在左边，别挡住后面的人） |
| `shelf` | 1×2 | 货架 / 书架 |
| `table` | 1×1.1 | 餐桌 |
| `bed` | 2×1.3 | 床 |

## 4. 点缀物（只占 1 格）

`tree`（方方的树冠，像多邻国那棵）、`bush`、`lamp`（路灯 / 落地灯）、`bin`（垃圾桶）、`flowers`（花坛）、`plant`（盆栽）、`cooler`（饮水机）。

## 5. 玩家「我」：四个方向走路

| 文件 | 内容 |
|---|---|
| `me_down_0..3.png` | 正面走（朝镜头），4 帧 |
| `me_up_0..3.png` | **背面**走（往画面里面走），4 帧 |
| `me_side_0..3.png` | 侧面走（往右；往左由程序翻转），4 帧 |
| `me_idle_0..1.png` | 正面站着呼吸，2 帧 |

每帧 256×420，脚底对齐同一条线。

## 6. NPC 额外姿势（每个角色）

现在 NPC 只能站着。下面这些有了，场景会更真：

- `sit`：坐在长椅 / 沙发上；
- `behind`：站在柜台后面，只画腰以上；
- `give`：双手递东西（给道具那一刻用）；
- `wave`：挥手打招呼（2 帧循环）。

## 7. 道具图标（NPC 送的东西）

目前用的是系统表情（🎟️ 优惠券、📋 比价表、🔧 二手货、⏰ 闹钟、💳 积分、🎫 补贴券）。
如果要统一画风，请出这一套 256×256 的图标，风格同上：优惠券、比价表 / 清单、二手旧物、钥匙、积分卡、补贴券、礼盒。

## 8. 交付优先级

1. 玩家四方向走路（尤其背面）；
2. `street` 一整套（地面、后排、building / kiosk / car / bench + 点缀）；
3. `home` 一整套；
4. 其余场景和 NPC 姿势。
