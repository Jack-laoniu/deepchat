# 城市旅游数据：采集方法和西安关卡设计

## 一、为什么要先采集数据

关卡里的景点、价格、预约规则、坑，必须是真的。大模型能讲个大概，但会说错细节（价格、闭馆日、放票时间），而这些正是外国游客最容易栽跟头的地方。所以每个城市先建一份结构化数据，关卡只从数据里挑内容、加上笑点和个性化。

## 二、数据放在哪、长什么样

- 格式定义：`src/travel/schema.ts`
- 西安数据：`src/travel/cities/xian.json`（第一版，2026-10-25 采集）
- 校验：`src/travel/cities.test.ts`，每条都必须引用来源，景点引用的坑必须存在

每个城市包含：

| 部分 | 内容 | 关卡里怎么用 |
| --- | --- | --- |
| `entry` | 怎么到（高铁、机场、240 小时过境免签） | 开场：从哪来、签证情况 |
| `get_around` | 城内交通（去兵马俑的几种方式和价格） | 「假旅游大巴」场景的选项 |
| `areas` | 住哪一片 | 选住宿 |
| `sights` | 景点：一句话卖点、门票、预约、时长、人流（1–5）、体力（1–5）、适合谁、不适合谁、相关的坑 | 地图、二选一、按画像挑景点 |
| `foods` | 美食：价格、辣度、是否清真、是否素食、吃的诀窍 | 回民街美食地图、忌口提问 |
| `pitfalls` | 坑：情境、后果、解决办法、影响哪些人、严重程度 | 「修坑」回合，按用户画像只出相关的坑 |
| `seasons` / `holidays` | 季节、天气、人流、节假日 | 「黄金周」类风险 |
| `todo` | 还没采集的 | 下一轮补 |

每一条都有：
- `conf` 可信度：high = 多个来源一致；medium = 来源少或有出入；low = 单一来源或凭常识
- `src` 来源（指向 `sources` 列表，每个来源标了类型：官方 / OTA / 旅行社 / 博客）
- `verify` 需要到官方渠道核实的地方

## 三、这次采集发现的问题

1. **各网站说法经常打架**。比如：
   - 大雁塔门票：¥10 和 ¥50 两种说法
   - 陕历博放票：提前 5 天 17:00、提前 7 天 8:00、提前 3 天，三种说法
   - 大雁塔喷泉时间：三套不同的时间表
   - 《长恨歌》场次：三套不同的时间
2. **来源大多是商业旅游博客**，有些像是 AI 写的，官方来源很少（只有华清宫官网一个）。
3. **结论**：数据要定期核实，最可靠的是官方公众号、官网、12306。这一步你有优势：你能直接看中文的官方公众号和小程序，外国做攻略的人看不了。

## 四、需要你核实的清单（按重要程度）

1. 兵马俑：现场还能不能买当天票（说法不一）
2. 陕历博：放票时间、每周哪天闭馆、唐墓壁画馆票价
3. 大雁塔：门票 ¥10 还是 ¥50、是否必须预约
4. 城墙：冬季关门时间、自行车租赁时间和年龄限制
5. 《长恨歌》：当季场次时间、12 月是否停演
6. 华山：索道价格
7. 兵马俑公交：306 路在火车站哪里上车、票价；地铁 9 号线到华清池后转哪路车
8. 240 小时过境免签：从咸阳机场入境后能不能去其他省份

## 五、根据数据设计的西安关卡（待你确认）

**英文，名字暂定 "First time in Xi'an"，主线是「一份适合你的西安几日游」。**

| 回合 | 玩法 | 用到的数据 | 暴露的偏好 / 坑 |
| --- | --- | --- | --- |
| 1. 到站 | 小故事：在西安北站下车，导航显示「距市中心 12 公里」 | `entry`、`pf_north_station` | 从哪来（北京高铁 / 飞机 / 240 小时过境）、和谁来、为什么来 |
| 2. 去兵马俑 | 小故事：火车站广场上穿制服的人拉你上「官方旅游大巴」 | `g_tw_*`、`pf_tw_touts`、`pf_fake_tickets` | 选地铁、306 路、打车还是请导游 → 预算敏感度、要不要导游（商家线索） |
| 3. 没票！ | 修坑 | `pf_tw_booking` | 提前用护照预约 / 让导游订 / 赌现场买（翻车） |
| 4. 回民街 | 地图：泡馍摊、肉夹馍摊、烤串摊、清真寺 | `foods`、`great_mosque`、`pf_beiyuanmen`、`pf_halal_outside` | 忌口（清真、素食、怕辣）；大爷送锦囊「往西走一条巷子，便宜又好吃」 |
| 5. 第二天连环两难 | 左右滑卡 | `city_wall`、`datang_everbright`、`everlasting_sorrow`、`shaanxi_museum` | 城墙骑车还是走、晚上去大唐不夜城挤人还是看《长恨歌》、早起抢陕历博的票、泡馍自己掰还是让店家切 |
| 6. 华山去不去 | 修坑 + 赌一把 | `huashan`、`pf_huashan_daytrip`、`pf_huashan_hidden_costs` | 怕不怕高、体力、预算；赌「走长空栈道」 |
| 7. 季节 | 选择 + 条件触发修坑 | `seasons`、`pf_golden_week` | 选十月初触发「黄金周」 |
| 8. 节奏、预算 | 选择、滑块 | 各景点时长和票价 | |
| 9. 终章 | 本地导游主持：自助、自助 + 一天导游、全程导游、跟团 | 全部 | 带什么：护照国籍、日期、离境机票（240 小时过境要用）、怕不怕高 |

**名著客串的机会**：西安是唐朝首都，大雁塔就是为唐僧建的。玩家在大雁塔可以叫唐僧进来：「贫僧取回的经书，就藏在这座塔里。贫僧走了十四年，你们这四天，倒是不必那么赶。」这是和北京关最不一样的亮点。

## 六、以后每个城市都按这个流程

1. 采集：搜官方和主流攻略，填进数据文件，标来源和可信度
2. 核实：对照官方渠道，把 `verify` 一条条清掉
3. 设计：从数据挑 6–9 个场景，写成关卡
4. 定期复查：价格和规则变了就改数据，关卡跟着改
