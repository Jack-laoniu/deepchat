# 1.0 上架与运营方案

> 平台规则变化很快，以下按 2026 年 10 月能查到的官方文档整理。提交前请再打开各平台的官方页面核对一遍。

## 0. 先说结论：上哪些平台

| 平台 | 能不能上 | 形式 | 优先级 |
| --- | --- | --- | --- |
| **ChatGPT（OpenAI）** | 能 | 2026 年 7 月起「Apps」改名为 **Plugins**，进 ChatGPT 和 Codex 共用的插件目录；我们的 MCP 服务器 + 游戏界面就是一个带界面的插件 | 第一 |
| **Claude（Anthropic）** | 能 | **Connectors Directory**，按 **MCP App**（带交互界面的远程 MCP 服务器）提交；任何付费 Claude 账号都能提交 | 第一 |
| **DeepSeek** | **没有第三方应用商店** | DeepSeek 目前没有面向开发者的插件/应用上架渠道。能做的是：把网页版的生成模型换成 DeepSeek API（便宜、国内访问快），然后通过国内渠道分发 | 第二 |
| MCP 公共目录 | 能，免费 | 官方 MCP Registry、Smithery、mcp.so、PulseMCP、Glama、魔搭 ModelScope MCP 广场 | 顺手做 |
| 国内渠道 | 视合规情况 | 网页版 + 微信分享、小红书/抖音内容引流；之后可考虑微信小程序、扣子 Coze 插件 | 1.1 以后 |

## 1. 这次已经在代码里处理好的

- **隐私政策**：`docs/privacy.md`，线上地址 `https://<域名>/privacy`。按代码实际行为写的：MCP 模式不存储；网页版会把需求发给模型服务商、存最近 30 份关卡、IP 只在内存里留 1 小时等。中英双语。
- **用户协议**：`docs/terms.md`，线上地址 `https://<域名>/terms`。
- **运营者信息**：在服务器 `/etc/need-quest/config.json` 里加 `legal` 一节（模板见 `deploy/config.example.json`），填 `operator`（个人或公司名）、`contact`（联系邮箱）、`effectiveDate`（生效日期）。**不填的话页面会显示「待填写」，审核一定会被拒。** 模型服务商名称会按配置自动写（配了 DeepSeek 就显示 DeepSeek）。
- **网页首页**底部加了「隐私政策 / 用户协议」链接（在 ChatGPT/Claude 里不显示）。
- **工具标注**：`start_need_quest` 现在声明了 `title`、`readOnlyHint: true`、`destructiveHint: false`、`idempotentHint: true`、`openWorldHint: false`，两个平台都要求。
- **工具描述**改了两处容易被拒的地方：
  - 原来写「用户想做任何事但细节模糊时都调用」，触发范围太宽；现在限定为「需要做决定/规划、关键信息不清楚，或用户点名要玩」，并写明简单问题不要调用。OpenAI 会拒掉试图影响模型选择其它插件的描述。
  - 原来让模型「把你对这个用户的记忆」写进关卡；Claude 提交时有一项「对话数据收集」的承诺，OpenAI 也审数据最小化，所以改成只用本次对话里和这个需求有关的内容，并禁止带入敏感个人信息。
- **ChatGPT 组件专属域名**：组件资源带上了 `openai/widgetDomain`（取自访问域名），上架时需要。
- **商店截图**：`docs/store/` 里 4 张 1150px 宽的 PNG（狗狗示例关卡），可直接用于 Claude 轮播图（要求 3–5 张、PNG、宽 ≥ 1000px、只截应用部分）。正式提交最好在 Claude/ChatGPT 里实际跑一局再截一套中文版。

## 2. 上架前你需要自己做的

1. **服务器上线并部署这个版本**：把本分支合并到 `claude/need-quest` 会自动部署。
2. **填 `legal` 配置**，打开 `https://<域名>/privacy` 确认没有「待填写」。
3. **准备一个支持邮箱**（两个平台都要 support contact）。
4. **图标**：一个正方形 PNG（ChatGPT 要 64×64、小于 5KB 的版本；Claude 要一个清晰的方形图标）。可以用向导乐乐的头像。
5. **在两个平台上先自测**：
   - ChatGPT：设置 → 开发者模式 → 添加 `https://<域名>/mcp`，在网页版和手机 App 上各玩一局（审核会在两端都测）。
   - Claude：设置 → Connectors → 添加自定义连接器 `https://<域名>/mcp`，每个工具至少调用一次（提交表单要你确认做过）。

## 3. ChatGPT 插件目录提交清单

入口：OpenAI Platform 的插件/应用管理页（需要**已验证身份的 OpenAI 组织**，只有组织 Owner 或有应用管理写权限的成员能提交）。

- [ ] MCP 地址：`https://<域名>/mcp`；**域名验证**（平台给一个 token，要求在你的域名上返回，到时把 token 发我，我加一个路由）
- [ ] 认证方式：无（我们不需要登录）
- [ ] 名称：Need Quest 需求闯关；副标题、长描述、分类（建议 Lifestyle 或 Productivity）、图标
- [ ] 网站、支持链接、**隐私政策 `/privacy`、服务条款 `/terms`**
- [ ] 每个工具的说明：只读、不对外部系统产生影响
- [ ] 内容安全策略：组件只从 `fonts.googleapis.com`、`fonts.gstatic.com` 加载资源（代码里已声明）
- [ ] **5 个正向测试 + 3 个反向测试**（见下）
- [ ] 开放国家/地区：中国大陆用户本来就用不了 ChatGPT，可以先选全部
- [ ] 不放广告、不做支付、内容适合所有年龄（我们都满足）

**正向测试用例**（期望结果写「形态」，不写具体台词，因为模型每次输出不同）：

1. 「我想养只狗，但不知道养什么」→ 调用 `start_need_quest`，出现游戏界面；通关后对话里收到一段需求总结
2. 「帮我规划一下装修预算，我也不太清楚要什么」→ 出现游戏，包含预算滑杆或选择题，总结里有预算区间
3. 「I want to set up a home gym but I'm not sure where to start」→ 英文关卡，界面和朗读为英文
4. 「想给爸妈买个手机，用 Need Quest 帮我理一下」→ 用户点名调用，出现游戏
5. 玩完一局后说「按刚才的结果给我详细方案」→ 模型不再调用工具，直接基于总结给方案

**反向测试用例**（不应调用）：

1. 「1 美元等于多少人民币？」→ 直接回答，不调用
2. 「把这段话翻译成英文：……」→ 不调用
3. 「我要买 iPhone 17 Pro 256G 黑色，帮我比一下京东和天猫的价格」（需求已经很明确）→ 不调用

## 4. Claude 连接器目录提交清单

入口：[claude.ai/directory/manage](https://claude.ai/directory/manage) → Submit new → MCP connector。任何付费 Claude 账号都能提交；提交后自动扫描，通过就以 Community 连接器上架，部分会人工审核。卡住了可以发邮件到 mcp-review@anthropic.com。

- [ ] Connection：`https://<域名>/mcp`
- [ ] Tools：自动同步，确认没有「缺少标注」的警告（已修）
- [ ] Listing：名称（≤100 字）、一句话介绍（≤200 字）、描述（≤2000 字）、1–5 个分类、文档地址（可以用 GitHub README 或网站首页）、隐私政策 `/privacy`、支持联系方式、图标、URL slug（**发布后不能改**，建议 `need-quest`）
- [ ] Use cases：只读、不需要账号
- [ ] Authentication：不需要登录
- [ ] Data handling：底层是我们自己的服务；不处理健康数据；没有赞助内容

- [ ] Compliance：7 项承诺全部勾选（目录规范、第一方 API 使用、金融交易、AI 媒体生成、提示注入、对话数据收集、公开文档）
- [ ] MCP App 轮播图：3–5 张 PNG，宽 ≥ 1000px，每张附一句对应的提问文字，不接受视频/GIF

**建议的一句话介绍**：
- 中：把一句模糊的需求变成一局小游戏，玩完就得到一份理清楚的方案。
- EN: Turn a vague need into a quick, Duolingo-style game — finish it and Claude gets a clear picture of what you actually need.

## 5. DeepSeek 和国内怎么做

DeepSeek 没有插件商店，所以「上 DeepSeek」的实际做法是：

1. **网页版改用 DeepSeek 生成**：配置里 `provider` 填 `openai`，`openai.baseUrl` 填 `https://api.deepseek.com`，`model` 填 DeepSeek 当前的对话模型名。隐私政策会自动写成「DeepSeek（深度求索）」。成本比 Claude/GPT 低很多，适合免费开放给国内用户。上线前用 `node server.mjs --check 想养只狗` 跑一次完整生成，确认关卡质量。
2. **国内合规（重要）**：面向中国大陆公众提供生成式 AI 服务，按《生成式人工智能服务管理暂行办法》需要做**备案或登记**（调用已备案大模型的应用，一般走属地网信办的「登记」，比自研模型的备案简单）；服务器在大陆还需要 **ICP 备案**；按 2025 年 9 月起施行的《人工智能生成合成内容标识办法》，AI 生成的内容要有显式标识（可以在关卡和需求清单上加「AI 生成」字样，需要的话我来加）。没办完这些之前，建议：服务器放香港/海外、不做付费、不做大规模国内投放，以小范围体验为主。
3. **其它国内入口**：魔搭 ModelScope 的 MCP 广场可以免费提交 MCP 服务器；扣子（Coze）等平台有插件市场，但多数不支持我们这种自带界面的 MCP App，只能作为普通工具接入，体验会打折，放到 1.1 以后再评估。

## 6. 获得流量以后怎么运营

### 6.1 先定目标和指标

1.0 阶段不追求变现，目标是**证明「玩一局比填问卷更能说清需求」**，看四个数：

| 指标 | 怎么算 | 1.0 目标参考 |
| --- | --- | --- |
| 开局率 | 输入需求后真正开始玩的比例 | > 70% |
| 通关率 | 开局后玩到需求清单的比例 | > 40% |
| 分享率 | 通关后点分享海报/邀请朋友的比例 | > 10% |
| 再玩率 | 7 天内再来闯一个新需求的比例 | > 15% |

现在服务器日志里已有生成次数、失败、兜底关卡的记录，可以先用 `journalctl -u need-quest` 粗看。要看上面四个数，需要加一个**匿名计数**（只记事件和时间，不记需求内容、不记 IP），加之前要同步更新隐私政策——你确认后我来做。两个目录上架后，Claude 的开发者门户会提供服务器健康和使用量数据，ChatGPT 平台也有调用统计。

### 6.2 流量从哪来

1. **平台内（最重要、最省钱）**：目录里的排名主要看描述是否准确、被调用后用户体验好不好。所以优先保证：生成速度（现在 30–120 秒，太慢会被用户关掉）、失败率低、在手机上好用。上架后每周看一次「哪些需求生成失败或走了兜底关卡」，修掉高频的。
2. **分享裂变（已有基础）**：通关后的「需求人格」海报、「让朋友帮我选」邀请链接是天然的传播点。运营上可以：
   - 每周出一个「本周热门需求」主题（买车、装修、养宠物、考研选校、给爸妈买手机），做成示例关卡放首页；
   - 海报文案多做几版，看哪版分享率高。
3. **内容平台**：小红书、抖音、B 站、即刻、X / Reddit（r/ChatGPT、r/ClaudeAI）。最有效的内容形式是**录屏**：「我跟 AI 说想养狗，它让我玩了个游戏，结果发现我其实不适合养狗」这类反转故事。每个热门需求一条，日更一周试水。
4. **开发者社区**：作为一个 MCP App 的完整开源案例（同时支持 ChatGPT 和 Claude、单文件部署）发到 GitHub、V2EX、掘金、Hacker News「Show HN」、Product Hunt，能带来第一批种子用户和反馈。
5. **MCP 公共目录**：Smithery、mcp.so、PulseMCP、官方 MCP Registry 都提交一遍，零成本。

### 6.3 成本控制

- 在 ChatGPT/Claude 里玩，关卡由宿主模型生成，**我们几乎没有模型成本**，只有服务器费用——这是最该推的入口。
- 网页版每局都花我们的 API 额度：配置里已有每 IP 每小时、每天总量、并发的限额。流量起来前先把 `perDay` 设成你能接受的预算（例如每天 200 局 × 单局成本），网页版换 DeepSeek 能把单局成本降一个数量级。
- 相同需求有缓存，热门主题做成固定示例关卡更省钱。

### 6.4 用户反馈闭环

- 在需求清单页加一个「这份方案有用吗 👍/👎」（匿名），配合上面的计数一起做；
- 支持邮箱的来信每周整理一次；
- 每两周发一个小版本，更新日志同步发到 GitHub Release 和社交账号。

### 6.5 之后的变现方向（1.0 不做，先记下）

- 网页版高级模式：更长的关卡、导出 PDF 方案、多人一起玩（家人一起选）；
- 行业版：给装修公司、宠物店、4S 店、留学中介做「客户需求问诊」，按月收费——这是最贴合产品本质的商业模式；
- 注意：OpenAI 目录要求插件里不放广告，Claude 也要求申报赞助内容，所以平台内保持干净，变现放在自己的网页版和 B 端。
