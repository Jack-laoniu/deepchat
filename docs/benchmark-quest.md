# 标杆关：第一辆车，油车还是电车？

> **状态**：已做成可玩版本（`src/lessons/car.json`，首页第一个示例）。
>
> 这一关**人工逐句打磨**，不靠 AI 生成。它用来定义「好的关卡长什么样」：节奏、台词、玩法搭配、最后给用户的东西。之后 AI 生成的关卡都以它为标准（作为示例喂给模型，也作为评审的对照）。

---

## 1. 为什么选这个需求

| 需要体现的 | 「第一辆车」为什么合适 |
|---|---|
| **受众广** | 几乎每个家庭都会遇到；油车还是电车是当下最常见的纠结 |
| **藏着「表单问不出来」的关键条件** | 决定油车还是电车的往往不是喜好，而是**有没有固定车位能装充电桩**、每天开多远、过年回不回老家。用户自己都没意识到，游戏能把它们「演」出来 |
| **多方意见打架** | 销售想让你加钱，懂车的朋友是电车党，老司机信油车，伴侣管钱，长辈怕不安全。正好用上我们性格鲜明的角色 |
| **真金白银，有坑** | 「落地价」里藏着金融服务费、精品加装、保险捆绑；电车还有充电桩安装费。适合我们的「方案清单 + 价格」 |
| **生活场景丰富** | 通勤（无文字的一天）、停车位置（摆进生活）、提车后第一个月（连环取舍）、过年回老家（Boss），每种玩法都用得自然，不是硬塞 |
| **适合传播** | 「你是油车派还是电车派」天然有话题，朋友之间会争，分享海报和「让朋友帮我选」都能用上 |

---

## 2. 体验目标

- **时长 5～7 分钟**，7 个回合（现在的关卡是 12～16 个回合，太长）
- 玩完用户会说：「它问出了我自己都没想到的事。」举例：「原来我小区没固定车位，买电车会很麻烦。」
- 全程**不出现**问卷式提问，比如「请选择您的通勤距离」。所有信息都从剧情、对话和操作里来
- 方案清单**一直在屏幕上长**，每次选择都看得到它变化，最后不是「突然出现一份报告」

---

## 3. 三幕结构

```
第一幕 引子（45 秒）       第二幕 摸清情况（3～4 分钟）                          第三幕 决战 + 揭晓（1 分钟）
┌──────────────┐   ┌──────┬──────┬──────┬──────┬──────┐   ┌──────────┬──────────┐
│ ① 楼下的争吵 │ → │② 地图│③ 一天│④ 车位│⑤ 加装│⑥ 第一个月│ → │ ⑦ 春节回家 │ 方案 + 人格 │
│   （剧情）   │   │ 打听 │ 无文字│ 摆进 │ 整理 │ 连环取舍 │   │  （Boss）  │   + 分享    │
└──────────────┘   └──────┴──────┴──────┴──────┴──────┘   └──────────┴──────────┘
```

## 4. 逐回合设计

### ① 楼下的争吵（剧情 · 听力故事）

**目的**：用一个真实的小冲突开场，让用户觉得「这说的就是我」；顺便问出用车的主要场景。

**场景**：小区楼下，晚上 8 点，阿杰刚把新电车停好，老王拎着菜路过。

> **旁白**：小区楼下，阿杰刚提了电车。
> **老王**：电车？冬天续航打七折，你等着排队充电吧。
> **阿杰**：王叔，我一公里一毛钱，你一公里六毛。
> **老王**：那是你有地方充。
> **阿杰**：……（看向你）你呢？你天天开去哪儿？

**提问**（选项 + 可以自己说）：
- 🏢 天天通勤上班 · 🛒 周末买菜遛娃 · 🛣️ 常跑长途 · ✍️ 自己说

**关键**：老王那句「那是你有地方充」是**伏笔**，第④回合会回收。

---

### ② 在小区和 4S 店之间打听（地图）

**目的**：三个人各说一面，把「钱、套路、家里意见」都摊开。

| 地点 | 谁 | 问出什么 |
|---|---|---|
| 物业办公室 | 小北（物业经理） | **能不能装充电桩**：「装桩要车位产权或租赁合同，还要业委会签字。你车位是买的还是租的？」→ 选项：买的 / 租的 / 没固定车位 |
| 4S 店 | 大刘 | **落地价的套路**：「裸车 13 万 8，今天定送脚垫！金融贷款的话首付只要 3 万，就收 4000 服务费。」→ 选项：全款 / 贷款 / 先问清楚服务费 |
| 家里 | 美姐 | **预算和谁开**：「上限多少？我也要开的，我可不会倒车入库。」→ 预算滑块在这里出现；另问是否两个人开 |

**隐藏条件**：选了「没固定车位」，会打上 `no_parking` 标记，后面第④回合和 Boss 会因此出现不同的坑。

---

### ③ 你的一天（无文字的一天）

**目的**：不问「你每天开多少公里」，而是让用户「过」一天，自然暴露用车频率和距离。

| 时刻 | 场景道具 | 选项（只有图标） | 记录下来的事实 |
|---|---|---|---|
| 07:30 | ⏰ | 🚗 开车上班 / 🚇 地铁上班 | 是否天天通勤开车 |
| 12:30 | 🏢 | 🏢 一直在公司 / 🚗 中午要出去跑 | 白天是否频繁用车 |
| 18:30 | 🌇 | 🛒 顺路买菜接孩子 / 🏠 直接回家 | 城市短途多不多 |
| 22:00 | 🌙 | 🔌 车停楼下充电 / 🅿️ 停路边 | 晚上车停哪（再次确认充电条件） |

---

### ④ 车晚上睡在哪（摆进生活 · 街道场景）

**目的**：回收第①回合的伏笔「那是你有地方充」，让用户**亲手**体会到停车和充电的问题。

- **场景**：小区（街道版），有三个位置：🅿️ 自家固定车位 · 🌳 路边临时车位 · 🏢 公司地下车库
- **要摆的东西**：🚗 你的车 · 🔌 充电桩
- **不合适的位置**：
  - 充电桩放到「路边临时车位」→ 晃一下，提示「路边不让装桩，只能去公共桩排队」
  - 第②回合选了「没固定车位」时，「自家固定车位」是**灰色、锁住的**，用户只能在剩下的里选，非常直观

---

### ⑤ 4S 店的「加装清单」（整理归类）

**目的**：把销售的加钱套路变成「整理」，让用户自己决定，同时学会砍掉什么。

| 卡片 | 估价 | 说明（给下游 AI） |
|---|---|---|
| 🛡️ 原厂贴膜 | ¥4,800 | 外面贴膜一般便宜一半 |
| ✨ 精品大礼包 | ¥3,000 | 脚垫、香水座、行车记录仪，实际价值很低 |
| 📈 延保 3 年 | ¥5,000 | 三电系统本身有 8 年质保（电车） |
| 🤖 高阶智驾 | ¥20,000 | 高速通勤多才值得 |
| 🪑 座椅通风 | ¥3,000 | 南方夏天体感明显 |
| 🔌 家用充电桩安装 | ¥2,000 | 有的品牌送桩不送安装 |

筐：**必须 / 有更好 / 不要**。小芳在旁边吐槽：「精品大礼包？那个香水座成本二十块。」

---

### ⑥ 提车后的第一个月（连环取舍 · Reigns 式）

**目的**：让用户「过」一遍真实的用车生活，看哪条槽（钱 / 省心 / 效果 / 安全）先撑不住。

| # | 谁 | 情境 | 左 | 右 |
|---|---|---|---|---|
| 1 | 阿杰 | 「公共桩排了 40 分钟，后面还有三辆。」 | 等着 · 省心 −20 | 去远一点的快充 · 多花 ¥30 |
| 2 | 大刘 | 「首保来店，顺便做个 600 块的养护套餐？」 | 拒绝 | 做了 · 多花 ¥600，省心 +10 |
| 3 | 美姐 | 「我开出去把保险杠刮了。」 | 自己掏钱修 · 多花 ¥1,500 | 走保险 · 明年保费多 ¥800 |
| 4 | 老王 | 「下雪了，续航只剩一半，明天还开吗？」 | 照开 · 安全 −15 | 坐地铁 · 省心 −10 |

**油车分支**（第③回合选了长途多、或第④回合充电条件差）：卡 1 换成「油价又涨了，这个月油费 1,100」。

---

### ⑦ Boss：春节回老家（Boss 战 + 激昂 BGM）

**目的**：最典型、最让人焦虑的场景。在这里检验前面所有选择。

- **危机**：大年二十九，800 公里回老家。
  - 电车：高速服务区充电排队 2 小时，车里坐着阿姨和孩子。
  - 油车：没有排队问题，但这一趟油费 + 路费超过 ¥600。
- **阿姨**：「你们几点能到？天黑开车我不放心。」
- **对策**（选一个）：
  - 🔋 出发前规划充电点、错峰出发
  - 🚄 长途坐高铁，车留在城市
  - 🔀 买插电混动 / 增程，长短途都兼顾
- **赌一把**：🎲 直接开，到时候再说。前面打了「没固定车位」或「常跑长途」标记时翻车：「服务区排了 3 小时，年夜饭没赶上。」

## 5. 揭晓：用户最后拿到什么

1. **方向结论**（用户自己选出来的，不是 AI 拍板）。例如：「你更适合**增程 / 插混**：通勤短，但每年要跑两次长途，而且小区装不了桩。」
2. **落地价明细**（清单一直在长，这里是最终版）：

| 项 | 例：15 万级电车（**估算**） |
|---|---|
| 裸车价 | ¥138,000 |
| 购置税 | 新能源车 2026–2027 年减半征收（**以当地政策为准**） |
| 保险（首年） | ¥5,500 |
| 上牌 / 杂费 | ¥500 |
| 充电桩安装 | ¥2,000 |
| 用户保留的加装 | 按第⑤回合结果 |
| 被砍掉的套路 | 精品包、原厂贴膜……「替你省下 ¥7,800」 |

3. **风险清单**：用户在第⑥回合和 Boss 接受了哪些代价
4. **给 AI 的超级提示词**：带着所有事实，去问具体车型
5. **需求人格海报**：油车派 / 电车派 / 两头兼顾派 / 精打细算派

---

## 6. 台词规则（去 AI 腔）

这一关的台词都按这几条写，以后也是 AI 生成台词的「编辑标准」：

1. **一句话只说一件事**，最多 20 个字。真人吵架不说长句。
2. **要有具体的数字和东西**：「一公里一毛钱」「香水座成本二十块」，不要「性价比很高」「需要综合考虑」。
3. **每个人有自己的口头禅和视角**：
   - 老王：「我开了二十年车」，只信经验
   - 阿杰：张口就是数字和参数
   - 大刘：「今天定的话……」，回避问题时打哈哈
   - 美姐：「这钱值吗？」
   - 阿姨：「安全不安全？」「过年回来吗？」
   - 小芳：替用户说出心里话，「他就是想让你加钱」
4. **禁用**：句尾的「～」、「让我们一起」、「值得注意的是」、「综上所述」、「亲」、「哦」开头的客服腔
5. **选项不对称**：现实里的两难常常是一边是诱惑、一边是麻烦，而不是两个都很合理
6. **允许冲突和吐槽**：角色之间可以互相拆台，比如老王说完，阿杰翻白眼

## 7. 这一关验证什么（怎么判断做好了）

找 5 个真的在考虑买车的人试玩（录屏或在旁观察）：

| 指标 | 目标 |
|---|---|
| 完成率 | ≥ 80% 玩到最后 |
| 时长 | 5～7 分钟 |
| 「它问出了我没想到的事」 | ≥ 3/5 的人能说出一个具体例子 |
| 愿意分享 | ≥ 2/5 的人主动点分享或「让朋友帮我选」 |
| 卡住的地方 | 记录每一处犹豫超过 5 秒的地方，逐个修 |
